# RE:STUDY

개인 PDF, 개념 정리, 문제 은행과 오답 복습을 연결합니다. 현재 버전은 React/Vite와 Supabase Auth·PostgreSQL·비공개 Storage·Edge Functions를 사용합니다. 이전 로컬 전용 버전은 `feat/local-prepared-content`의 `3a50476`과 [이전 실행 안내](docs/legacy-local-guide.md)에 보존했습니다. 기존 `data/` 자료를 클라우드에 자동 업로드하지 않습니다.

## 실행

Windows에서 **start.bat**를 실행하면 `http://localhost:3000`이 열립니다. Node.js 22.12 이상이 필요합니다. 처음에는 `npm ci`로 패키지와 OCR 파일을 준비하며, 계정·PDF·학습 기록 접근과 AI 요청에는 인터넷 연결이 필요합니다.

`.env.example`을 `.env.local`로 복사하고 Supabase 공개 URL과 publishable 키를 입력합니다. 이 두 값은 브라우저용 공개 설정입니다. AI 키·service role·마스터 키를 `VITE_` 변수에 넣지 마세요.

```powershell
npm ci
npm run dev
npm run build
npm start
npm test
npm run typecheck
```

현재 Supabase 프로젝트는 `tfjsrdfnrybepxpdfqfz`(Restudy), GitHub 소스 저장소는 `322bono/ReStudy`입니다. 서버 초기 설정과 배포는 [클라우드 운영 안내](docs/cloud-setup.md)를 따릅니다. Python 백엔드는 이전 로컬 버전 보존용이며 새 화면의 실행에 필요하지 않습니다.

## 학습 흐름

1. **내 자료 → 파일 추가**에서 전체 PDF를 미리 보고 실제 PDF 페이지 범위·제외·목차·분석 방식을 고릅니다. 한 번에 10개, 합계 50MB, 한 PDF 500쪽까지입니다. 원본 전체를 비공개로 보존합니다.
2. 선택 범위의 텍스트 또는 로컬 OCR, 페이지 이미지와 문항 후보를 저장합니다. 중단한 작업은 체크포인트부터 이어갑니다. 자동 크롭은 후보이므로 콘텐츠 관리에서 번호·영역·공통 지문·이어지는 쪽을 검토합니다.
3. **자료 상세 → 목차·개념**에서 정리를 읽고 기본 콘텐츠를 준비합니다. 자동 분석은 목차와 단원부터 시작하며 모든 원본 문항을 심층 분석하지 않습니다. 기본값은 단원당 개념 퀴즈 5개와 연습문제 5개입니다. API 연결이나 한도가 부족하면 남은 작업을 보관합니다.
4. **콘텐츠 준비·가져오기**에서 API 요청 또는 외부 분석 작업을 만듭니다. 프롬프트에 실제 문서/작업 ID, 범위, 전체 JSON Schema가 포함됩니다. 선택 범위 PDF를 내보내 외부 AI에 첨부한 뒤 결과를 붙여넣습니다. 가져오기 검사는 AI를 호출하지 않습니다.
5. `restudy.v1` 100문항은 기본 20개씩 5분할입니다. 순서가 달라도 참조가 도착할 때까지 보관하고, 같은 분할 재등록은 중복을 만들지 않습니다. 완전 동일 문항만 제외합니다. 실제 내용·정답·해설을 검토한 문항만 학습에 사용합니다.
6. **학습하기 → 문제 은행**에서 여러 자료·단원·개념, 목적·형식·난이도·순서·개수를 선택합니다. 문항이 부족하면 실제 개수를 알리고 시작하며 자동으로 AI를 호출하지 않습니다.
7. **오답 노트**에서 원본 번호를 등록합니다. 상세에서 개념과 암기사항을 먼저 읽고 개념 퀴즈 5개·연습문제 10개·유사문제·원본 재풀이로 이동합니다. 분석이 없으면 명시적으로 API/외부 작업을 선택합니다. 중복 번호는 원본 페이지에서 구분합니다.
8. 원본 재풀이는 저장한 깨끗한 이미지와 세션 스냅샷을 사용합니다. 정답 확인 전에는 이전 풀이와 개념 태그를 숨깁니다. 개념 이해도와 원본 정답 횟수는 별도로 저장합니다.

자유 답변의 의미를 AI처럼 채점하지 않습니다. 준비된 정답과 일치하면 자동 채점하고, 일치하지 않는 단답/빈칸은 정답을 확인해 직접 채점합니다. 오개념 교정은 저장된 선택지 해설을 사용합니다.

## 데이터와 한계

- PDF/크롭은 비공개 Storage, 콘텐츠와 이력은 계정별 RLS로 저장합니다. IndexedDB는 소유자별 캐시입니다.
- 생성 문항은 형식 검사와 교육적 검토가 별개입니다. 사용자 DB에 시연 문항을 넣지 않으며 개념 미등록을 그대로 표시합니다.
- 설정의 JSON/CSV 내보내기는 **원본과 계정/AI 비밀값을 제외한 학습 데이터**입니다. JSON 복원은 같은 계정에서 누락된 ID만 추가합니다. 원본을 열려면 기존 Storage 파일이 남아 있어야 합니다.
- API/외부 분석 모두 [동일 스키마](docs/restudy.v1.schema.json)와 저장 경로를 사용합니다. 유료 AI는 기본 차단됩니다. 무료 계정 확인은 사용자의 확인이며 실시간 과금 보증이 아닙니다.
- 자동 분리/OCR은 모든 교재에서 정확하지 않습니다. 흐릿한 스캔·복잡한 수식·번호는 관리 화면에서 확인하세요. 목차만 읽은 개념은 본문 확인 필요로 표시합니다.
- 실제 제공자 호출은 사용자가 API 키를 등록한 뒤 검증해야 합니다. 키가 없는 상태를 연결 성공으로 표시하지 않습니다.
