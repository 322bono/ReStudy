# 학습 흐름 개선 · 2026-11-02

사용자 추가 요구에 따라 기존 자료·계정·콘텐츠 ID·학습 이력을 보존하며 수정한다.

- 준비 작업은 개념 정리, 개념·기본 문제, 추가 문제 은행으로 구분한다. 외부 AI 작업은 전체 범위의 JSON 한 개를 가져오며, API만 작은 단위로 순서대로 처리한다. 과거 분할 작업은 기록을 보존한다.
- 개념 전용 작업은 문항 수 0을 허용하고 정의·공식·암기사항·카드를 저장한다. 교과서는 본문 개념에 집중하며 문제 번호 검출을 기본 실행하지 않는다.
- PDF.js는 Safari용 legacy 표시·워커 빌드를 함께 사용한다. OCR의 선택적 이미지 블록에는 문단·단어 배열이 없을 수 있으므로 구조를 검사한다.
- 파일 전체 50MB 앱 제한을 제거한다. 큰 원본은 비공개 Storage의 여러 객체로 저장하고 소유자 검증 후 합쳐 사용한다. 프로젝트 저장 용량, 브라우저 메모리와 페이지 처리 범위 한도는 남는다.
- API는 각 추론에 110초를 확보한다. 제한된 Edge 실행 시간 안에 두 번째 시도를 억지로 넣지 않고 상태를 저장한 뒤 이어간다. 제공자·프로젝트 그룹의 요청 간격은 서버에서 원자적으로 제어하고 재시도 시각을 지킨다. 키 추가로 공동 할당량을 우회하지 않는다.
- 브라우저는 백그라운드 작업을 조회하며, 완료된 단위를 재사용해 다음 단위로 이동한다. 현재 실행 중인 임대와 오래된 작업의 저장 권한은 토큰으로 구분한다.
- 오답 등록 후 저장된 크롭으로 분석을 요청하고 해설·개념·암기사항·추가 확인 문제를 저장한다. 기록 열람과 재풀이는 저장값을 조회한다. 맞힌 오답은 복습 대기에서 제외하고 보관하며, 다시 틀리면 대기에 남는다.
- 학습하기는 실제 저장 문항을 기준으로 학습 가능·검토 대기를 구분한다. 개념만 준비된 자료도 읽을 수 있다. 전체 유형·난이도와 여러 출처의 범위 선택을 지원한다. AI 생성 문항을 자동 승인하지 않는다.

검증은 자동 테스트, 타입 검사, 프로덕션 빌드, Edge 타입 검사, 공개 화면 확인으로 진행한다. 외부 제공자의 503·할당량·110초를 넘는 추론은 정상 응답으로 꾸미지 않는다.
