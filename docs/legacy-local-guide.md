# RE — 사전 콘텐츠 기반 로컬 학습

Windows PC의 PDF·개념·복습 문항·학습 기록을 연결하는 로컬 앱입니다. 생성형 AI, API 키, 사용자 계정, 클라우드 연결이 없습니다. 학습 문제·정답·교정 설명은 콘텐츠 관리에서 준비한 데이터만 사용합니다.

## 실행

**start.bat를 더블 클릭**합니다. 브라우저에서 [http://localhost:3000](http://localhost:3000)이 열립니다. 이 창을 닫거나 Ctrl+C로 종료합니다. 기존 `실행.cmd`도 같은 실행기로 연결됩니다.

현재 작업 PC에는 실행 환경과 화면 빌드를 준비해 두었습니다. 다른 PC에서 처음 준비할 때는 Python 3.11 이상, Node.js 22.12 이상과 패키지 설치를 위한 인터넷 연결이 필요합니다. 한 번 준비된 뒤에는 인터넷 없이 실행합니다. 실행기는 설치된 버전과 빌드를 먼저 확인하고, 준비된 파일을 실행할 때 패키지를 다시 내려받지 않습니다.

개발 명령:

```powershell
# Python 의존성 최초 설치
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
npm ci
npm run build
npm start
# 화면을 수정할 때는 별도 터미널에서 npm run dev (localhost:5173)
```

서버는 기본적으로 이 PC의 127.0.0.1:3000에서만 열립니다. 계정 없이 사용하는 개인용 앱이므로 외부 공개 서버로 배포하는 구성이 아닙니다.

## 처음 사용할 때

1. **내 자료 → 파일 추가**에서 과목과 종류를 정하고 PDF를 등록합니다. 한 번에 10개·합계 50MB, PDF 한 파일당 500쪽까지 지원합니다.
2. 전체 페이지를 처리하고 **모든 인식 문항의 PNG를 미리 저장**합니다. 학습할 때 PDF 분석이나 크롭을 다시 실행하지 않습니다.
3. **콘텐츠 관리 → 문항 연결·영역**에서 전체 크롭을 검토합니다. 번호·영역·시작 쪽을 수정하고 확인합니다. 공통 지문과 이어지는 페이지를 포함하는 여러 영역도 저장할 수 있습니다.
4. **가져오기·내보내기**에서 사전에 제작한 JSON 또는 이 앱의 콘텐츠 SQLite를 검사한 뒤 가져옵니다. 개념과 문제 은행을 직접 입력·편집할 수도 있습니다. [콘텐츠 형식](docs/content-format.md)을 참고하세요.
5. **오답 노트 → 오답 등록**에서 `47, 48`처럼 번호를 입력합니다. 중복 번호는 페이지로 구분합니다. 준비된 개념·문항이 있으면 개념 복습으로 이어집니다.
6. 저장된 선택지별 해설로 오개념을 교정하고 다른 문항으로 재확인합니다. 서술형은 정답을 펼쳐 직접 채점합니다.
7. 복습 후 **원본 다시 풀기**로 깨끗한 사전 크롭을 풉니다. 확대·필기·답 입력·자기 채점을 지원합니다. 원본 정답도 관리자가 등록한 경우에만 요청해서 확인할 수 있습니다.
8. 맞힘·틀림·다음에 풀기와 복습 일정을 저장합니다. 다음 실행에서 학습을 이어갑니다.

매핑이 없으면 **개념 미등록**, 매핑만 있고 은행 문항이 없으면 **학습 문항 미등록**으로 표시합니다. 앱이 개념이나 문제를 추측해서 채우지 않습니다. 실제 교재별 콘텐츠가 제공되지 않았기 때문에 사용자용 DB에는 시연용 문제 은행을 넣지 않았습니다.

## 자료 기반 학습

학습하기에서 한 과목의 여러 파일과 페이지 범위를 선택합니다. **선택 범위 안에 출처가 있는 사전 제작 문항**만 사용합니다.

- 문제 풀기: 객관식·OX·빈칸·단답형·서술형
- 암기하기: 플래시카드·문장 가리기·빈칸과 알고 있음/헷갈림/모름
- 개념 확인: 사전 질문과 정답을 이용한 확인·자기 채점

난이도·유형에 맞는 등록 문항이 부족하면 실제 개수로 시작합니다. 자료만 올려서 새 문제를 생성하지 않습니다. 개념 복습은 기본 3~5개이며, 연결 개념이 많으면 작은 묶음으로 이어갑니다. 아직 풀지 않은 문항과 오답률이 높은 개념을 우선하고 최근 정답 문항은 피합니다. 틀린 개념은 다른 등록 문항으로 재확인합니다. 다른 문항이 없으면 같은 문항임을 표시합니다. 재확인 3회 뒤에도 이해가 확인되지 않으면 미확인 상태를 유지합니다.

복습 간격은 정답 연속 횟수에 따라 1·3·7·14일로 늘어나고, 오답이면 다음 날로 돌아갑니다. 원본 문제 정답률과 개념 이해도는 별도로 기록합니다.

## 전처리와 로컬 OCR

문항 번호·텍스트 좌표·열 구조·벡터/이미지 경계·공통 지문·이어지는 표시를 활용합니다. 페이지를 일정한 크기로 나누지 않습니다. 정답·해설 페이지는 문제 이미지에서도 제외합니다. 원본 PDF와 정규화 좌표를 보관하며 크롭에는 PDF 주석을 포함하지 않습니다.

임의의 모든 교재에서 자동 경계가 정확하다고 보장하지 않습니다. 자동 추출은 **검토할 후보**이며, 불확실한 영역은 등록 단계의 관리 화면에서 확인해야 합니다. 사용자 수정은 문제 ID와 기존 이력을 유지합니다.

스캔본은 로컬 Tesseract가 설치되어 있으면 OCR을 사용합니다. 이 PC에는 한국어·영어 Tesseract를 tools/tesseract에 준비했으며 실제 스캔 OCR과 크롭 저장을 검증했습니다. OCR이 필요하면 Tesseract와 kor/eng 언어 데이터를 설치하고, PATH 또는 Windows 환경 변수 `TESSERACT_CMD`에 실행 파일 경로를 지정한 뒤 재시작하여 해당 자료만 다시 처리하세요. Windows 최초 실행 준비에서 검증된 OCR 파일을 한 번 받습니다. 준비 후에는 오프라인으로 실행하며 PDF 처리 중에는 다운로드하지 않습니다. scripts/setup_ocr.py에서 출처와 SHA-256을 확인할 수 있습니다.

## 저장·백업·기존 자료

모든 파일은 프로젝트의 `data` 아래에 있습니다. 선택적으로 Windows 환경 변수 `RE_DATA_DIR`로 다른 로컬 폴더를 지정할 수 있습니다.

- `re-local.sqlite`: 자료·문항·개념·문제 은행·다대다 매핑·오답·풀이·개념 이해도·복습 일정
- `files/`: 업로드 원본, 이미지 자료의 로컬 PDF 변환본
- `prepared/`, `crops/`: 등록 때 만든 페이지·문항 PNG와 수정 버전
- `backups/restudy-before-local.sqlite`: 이전 버전 데이터베이스의 일관된 백업

서버를 정상 종료한 뒤 **data 폴더 전체**를 복사합니다. DB만 복사하면 원본 이미지가 빠지므로 전체 폴더를 보관하세요.

이전 `data/restudy.sqlite`는 읽기 전용으로 이관하며 원본을 수정하지 않습니다. 자료·문항·오답·풀이·필기·시도 ID를 유지합니다. 기존 방식의 생성 학습 기록은 이력으로 보관하고 새 문제 은행으로 간주하지 않습니다. 이전 자료의 빠진 사전 크롭은 한 번 준비합니다. 준비가 끝난 자료는 재실행 시 재분석하지 않습니다.

자료 보관은 기본 목록에서 숨기는 작업입니다. 파일과 과거 기록은 삭제하지 않습니다. 콘텐츠 수정 뒤에도 이미 시작한 세션은 당시 문항·정답·해설·원본 이미지 사본을 사용합니다.

## 검증

```powershell
npm test
npm run typecheck
npm run build
```

실제 PDF fixture로 두 단 편집·표 숫자·그림·선택지·공통 지문·명시적 페이지 연속·중복 번호·정답 페이지·회전·주석 제외를 검사합니다. 콘텐츠 가져오기 원자성, 출처 범위, 과목 참조, 오개념 교정, 자기 채점, 동시 저장, 세션 사본, 이관·재접속 저장도 테스트합니다. 실제 Tesseract가 없는 환경의 해당 실행 테스트는 건너뛰고 결과에 표시합니다. 시연 자료는 테스트 전용 임시 폴더에만 사용합니다.

구성: React·TypeScript·Vite·Tailwind CSS·shadcn 방식 공통 UI, PDF.js / Python FastAPI·SQLite·PyMuPDF·OpenCV. Pretendard 폰트와 PDF.js worker/보조 자원도 로컬로 제공합니다.
