# 오답 분석 일관성과 풀이 전환 개선 · 2026-11-08

저장된 일부 AI 응답은 정답 칸과 해설 결론이 달랐고, 판단을 번복하는 초안 문장을 포함했다. 기존 검사는 JSON 구조만 검사했다. Gemma의 기존 MINIMAL 설정은 공식 API 문서상 추론 비활성 설정이다.

## 분석 저장

- 원본 보기·그림·선지를 함께 보고 판단을 끝낸 최종 해설만 요청한다. 원본 문장을 의도대로 바꾸거나 답에 끼워 맞추지 못하게 명시한다.
- 오답 분석에서 Gemma 추론은 공식 지원값 HIGH로 켠다. Google Flash의 기존 무료 프로젝트 검증과 LOW 설정은 유지한다. Gemma의 HIGH/MINIMAL 외 추론값은 사용하지 않는다.
- 명시적 정답 번호 불일치와 자기 정정 초안을 저장 전에 거부한다. 거부 이유는 형식 오류와 구별하며 본문을 로그에 남기지 않는다.
- 다른 무료 모델이 같은 원본을 독립적으로 풀어 정답이 일치해야 저장한다. 이전 답은 다음 모델에 전달하지 않는다. 불일치하면 세 번째 모델까지 확인한다. 끝내 합의가 없으면 정답을 확정하지 않는다. 모델 간 합의는 정답 보장이 아니다.
- 확인 단계마다 기존 영구 작업과 quota 예약을 이용한다. 무료 모델/프로젝트 검증을 우회하지 않는다. 확인은 분석 때 수행하고 풀이·정답 열람 때 AI를 호출하지 않는다.
- 모순이 발견된 기존 분석은 화면에서 정답으로 노출하지 않는다. 해당 오답 상세를 열면 자동으로 재분석한다. 교체 전 분석은 supersededReview에 보관하며 문항 ID·오답 기록·풀이 세션 스냅샷은 변경하지 않는다.

## 전환과 Egress

- 수정하지 않은 필기를 문제 이동 때 다시 저장하지 않는다. 바뀐 필기는 하나의 순서 있는 저장 큐에서 처리하고, 화면은 즉시 이동한다. 저장 실패 시 최신 필기를 큐에 남기고 알린다. 나가기와 채점은 저장 완료를 확인한다.
- 다음 세 문항과 직전 문항의 저장된 이미지에 기존 소유자별 캐시·중복 요청 합치기를 적용한다. 전체 문제집을 미리 다운로드하지 않는다.
- 한 이미지의 접근 권한 검사에서 전체 세션과 필기 대신 지정한 스냅샷의 문항 ID·자료 ID·해당 영역·파일 경로만 읽는다. 스냅샷 인덱스는 정수로 제한하고 요청한 문항 ID와 일치하는지 검사한다. 기존 클라이언트는 스냅샷 목록만 읽는 호환 경로를 사용한다.
- 오답 상세와 정답 묶음 조회는 다른 세션·필기·학습 결과·다른 문항의 분석을 읽지 않는다. 관련 개념·문제 은행·유사 문항 연결은 유지한다.
- 채점마다 전체 홈 데이터를 새로 받지 않고 복습 완료 또는 나갈 때 갱신한다.
- 채점 저장 응답은 진행 상태만 반환한다. 클라이언트가 이미 가진 원본 스냅샷과 필기를 매번 다시 전송하지 않는다. 기존 클라이언트의 전체 응답 계약은 유지한다.
- 원본 화질·비공개 저장소·로그인·메뉴·학습 동작은 유지한다. 기존 PDF/이미지 IndexedDB 캐시는 유지한다.

읽기 전용 DB 표본에서 이미지 경로 조회의 JSON은 큰 세션 세 건 기준 364,975→397, 325,579→396, 274,244→414바이트였다. 이는 해당 조회의 데이터 크기이며 월간 전체 Egress 절감률이나 실제 기기 지연 시간 측정값은 아니다. 이미 집계된 월 사용량은 이 수정으로 되돌릴 수 없다.

공식 근거: [Gemma API 추론](https://ai.google.dev/gemma/docs/core/gemma_on_gemini_api), [Supabase Egress](https://supabase.com/docs/guides/platform/manage-your-usage/egress).

## 추가 요청: 작은 필기 도구막대

필기 모드일 때 문제 위에만 도구막대를 표시한다. 빨강·검정·파랑의 원형 팔레트, 세 가지 굵기, 펜과 획 지우개를 제공한다. 선택한 색과 굵기는 기존 Stroke 필드에 저장하므로 기존 필기와 함께 복원된다. 지우개는 현재 영역에서 포인터가 지난 경로와 닿은 획만 제거한다. 다른 페이지·영역의 필기는 유지하며, 필기 중 화면 이동 방지는 유지한다.
